# 三映CSV → 勘太郎CSV 変換アプリ（印刷勘太郎 連携）

三映様から届く印刷予定表CSV（**CSV-A**）を固定ルールで解釈し、人が確認・修正したうえで、印刷勘太郎の取込形式（**CSV-B・35列 A〜AI**）を **1案件1ファイル** で連携フォルダへ出力するWebアプリです。**AIは使いません**（変換はすべてルールベース）。勘太郎側はSFTPでこのフォルダからCSVを取り込みます（PULL方式）。

## 処理フロー

```
三映CSV（CSV-A：Shift_JIS/UTF-8、複数可）
   │  ① アップロード
   ▼
固定ルールで変換（sanei_config.yaml）
   ・本番/校正セクション分割、「裏」行の除外、受注№ごとに1案件へまとめる
   ・品名連結、用紙/印刷サイズ変換、色数の表裏分解、営業日で納品日計算、備考文面
   │  ② 画面で人が確認・修正（案件ごとに35列を表示。判断に迷う箇所は警告）
   ▼
案件ごとにCSV-B生成（1行目=全35列、2行目以降=N〜AB列のみ）
   │  ③ .tmpに書き切ってから rename（アトミック書込）
   ▼
連携フォルダ /data/incoming/ に 20260827_2603797-00-00_本番.csv …
   │  ④ 最後に .done ファイルを作成（転送完了の合図）
   ▼
印刷勘太郎が SFTP で .done を確認してから CSV を取込
```

## セットアップ

```bash
pip install -r requirements.txt
export APP_USERNAME=... APP_PASSWORD=... SECRET_KEY=...   # ログイン用
python -m app.main
# → http://localhost:8000 をブラウザで開く
```

変換ロジックだけを手元で試す場合（三映CSVは顧客情報を含むためリポジトリには入れない）:

```bash
python tools/run_sanei_demo.py path/to/CSV-A.csv --out ./out
python tests/test_sanei_converter.py   # 合成データでの単体テスト
```

## 「印刷勘太郎から求むものリスト」との対応表

| リストの項目 | 本アプリでの実装 | 勘太郎側と決めること |
|---|---|---|
| 1. SFTP接続情報 | 基本はPULL方式（勘太郎が取りに来る）。PUSH方式も `config.yaml` の `sftp.push_enabled` で対応可（paramiko・SSH鍵認証） | ホスト/ポート/アカウント、鍵ペアはアプリ側で生成し公開鍵を渡す |
| 2. CSVフォーマット | `sanei_config.yaml` の `output`（UTF-8・最小囲み・CRLF）と `csv_b_columns`（35列）。取込テスト済みの見本に準拠。コード変更不要 | セル内改行の扱い（`cell_newline`）の最終確認 |
| 3. 命名規則 | `{下版予定日}_{受注№}_{本番/校正}.csv`（`sanei_config.yaml` の `filename_pattern`）。同名がある場合は上書きせず `_2` を付与 | 正式な命名規則の合意 |
| 3. 配置先ディレクトリ | `config.yaml` の `output.dir`（既定 `data/incoming/`） | 実際のパス |
| 3. 処理済みファイルの扱い | `archive/` `failed/` フォルダを用意。UIで3フォルダの状況を可視化 | 勘太郎側が取込後に削除するか移動するか |
| .doneトリガーファイル | CSVを完全に書き切った**後**に `.done` を作成。SFTP PUSH時も CSV→.done の順で送信 | 「.doneを見つけるまでCSVに触らない」ルールの合意 |
| 不完全CSVの防止 | `.tmp` に書いて `os.replace()` でrename（アトミック）。PUSH時もリモートで rename | — |
| 発生頻度 | 画面で確定した都度、その案件数ぶんのファイルを出力 | 取込タイミング |
| SSH鍵認証 | パスワード不使用。Ed25519秘密鍵ファイルを参照（コードにハードコードしない） | 公開鍵の登録 |
| 固定IPアドレス制限 | ネットワーク側の設定事項。アプリサーバーのIPを固定し、勘太郎側FWで許可リスト化 | 許可IPの登録 |

## 運用上の設計判断

- **変換は固定ルール、確定は人**: AIを使わず、同じ入力なら必ず同じ結果になります。変換表にない寸法・「裏」だけの案件・未定義の文面などは握りつぶさず画面に警告として出し、人が確認してから出力します。
- **1案件1ファイル・全件検証してから書込**: 1件でも出力できない案件があれば1ファイルも書き出しません。出力後は確認画面を閉じ、同じ案件の二重出力（＝勘太郎への二重登録）を防ぎます。
- **ルールはすべて設定ファイル**: 固定値・変換表・備考文面・祝日・35列の定義は `sanei_config.yaml`。仕様変更はコードを触らずに反映できます（GAS版へ移す際はスプレッドシートへ転記）。
- **ログ**: すべての受付・変換・出力を `app.log` に記録します（いつ・どのファイル・何案件）。
- **保存先の注意**: Renderの無料プランではディスクが再起動で消えます。出力したCSVはSFTP送信するか、画面からダウンロードして回収してください。
- **セキュリティ**: ログイン必須、SFTPは鍵認証、出力ファイル名とダウンロードAPIはパストラバーサル対策済み。

## ファイル構成

```
printpro2/
├── sanei_config.yaml   # 変換ルール・CSV-B 35列の定義・出力形式（コード変更不要）
├── config.yaml         # 出力フォルダ・.done・SFTP・サーバー設定
├── requirements.txt
├── app/
│   ├── main.py            # FastAPI（API + 画面配信）
│   ├── sanei_converter.py # 三映CSV → CSV-B 変換エンジン（ルールベース）
│   ├── csv_writer.py      # アトミック書込・.done
│   ├── extractor.py       # 旧: Claude APIによる発注書PDF読取（現在の画面では未使用）
│   └── store.py           # 旧: 受注台帳（現在の画面では未使用）
├── static/index.html   # 画面（アップロード→案件ごとの確認→出力→フォルダ状況）
├── tools/run_sanei_demo.py      # 変換のデモ実行
├── tests/test_sanei_converter.py
└── data/
    ├── uploads/   # アップロードされた三映CSVの保管（監査用）
    ├── incoming/  # 勘太郎がSFTPで見に来るフォルダ
    ├── archive/   # 取込済
    └── failed/    # エラー退避
```
